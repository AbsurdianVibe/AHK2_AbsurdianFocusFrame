# Absurdian Focus Frame

![app icon](AbsurdianFocusFrame.png)

Welcome to **Absurdian Focus Frame**! This is my very first programming project.

## About the Project
This lightweight utility changes the appearance of the native dotted keyboard selection border on the Windows Desktop, replacing it with a modern, customizable highlight frame.

## Current Status: Version 1.1.6
The application is completely stable and fully functional for the Windows Desktop environment (Win11).

### Key Features
* **Customizable Frame:** Adjust border thickness, transparency, corner rounding and color in real-time.
* **Built-in GUI:** No more manual `.ini` file editing. The tool includes a responsive Settings panel accessible from the system tray.
* **Screen Color Sampler (Pipette):** A dedicated hardware-stabilized screen overlay (Click-Eater architecture) allows you to safely sample and extract colors from any pixel on your virtual screens, without triggering background applications.
* **Auto-theme Support:** Leave the color blank to automatically adapt to your system's current theme.

## Configuration
The application can be configured seamlessly via the GUI (right-click the tray icon and select "Settings"). Settings like border color (HEX), transparency, corner radiuses, and system autostart are saved dynamically.
